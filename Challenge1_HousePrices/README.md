# Challenge 1 · House Prices

Dự đoán SalePrice từ dữ liệu Ames Housing của Kaggle. Bộ source có một notebook EDA, bốn notebook mô hình và một notebook tổng hợp.
## Chạy trên Windows với VS Code
1. Mở PowerShell tại thư mục dự án. Dùng Python 3.11 hoặc 3.12 và chạy:

       py -m venv .venv
       .\.venv\Scripts\python.exe -m pip install -r requirements.txt
