## Hướng dẫn sử dụng

1. Sao chép kho lưu trữ về máy.

   ```bash
   git clone https://github.com/hthuonq/sgu-MAYHOC.git
   cd sgu-MAYHOC
   ```

2. Mở thư mục bài thực hành hoặc đồ án cần xem bằng VS Code.
3. Với mỗi đồ án, đọc `README.md` trong thư mục tương ứng để biết cách chuẩn bị dữ liệu, cài thư viện và chạy notebook theo thứ tự.
